# maestroFit

Persönliche Trainings-App für Krafttraining und Bodybuilding (Flutter/Dart, Android zuerst).

- **Nachschlagen:** Übungsbibliothek mit interaktiver Body-Map – Muskel antippen,
  passende Übungen finden; pro Übung primär/sekundär beanspruchte Muskeln und
  Bewegungsausführung.
- **Tracken:** Workouts schnell eintragen (Werte vom letzten Mal, Rest-Timer),
  Fortschritt mit Charts und Muskel-Heatmap auswerten.
- **Lokal:** Daten bleiben auf dem Gerät (SQLite/Drift), mit Export/Backup.
  Kein Konto, keine Werbung, keine Bezahlkurse im Kern.
